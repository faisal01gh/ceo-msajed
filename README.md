# ceo-msajed

هذا المستودع هو **المرجع المركزي الرسمي** لمشروع نظام الجمعية.

## القاعدة الأساسية

أي قرار يعتمد في المحادثات يجب تحديثه هنا أولًا بأول.  
عند الانتقال إلى محادثة أو مشروع جديد، يكفي الرجوع إلى هذا المستودع بدل إعادة شرح السياق كاملًا.

العبارة المختصرة المقترحة للمحادثات الجديدة:

> راجع مستودع `faisal01gh/ceo-msajed` واقرأ آخر حالة للمشروع ثم أكمل من آخر نقطة معتمدة.

## مراجع النظام

- النظام السابق والهوية البصرية المرجعية: `faisal01gh/ceo-office-tasks`
- هذا المستودع: المواصفات المعتمدة، قرارات العمل، الهيكل التنظيمي، النماذج والتصاميم الجديدة.

## قواعد مهمة

- لا يتم تعديل الإنتاج أو نشر تغييرات تشغيلية إلا باعتماد صريح.
- لا تعتبر النماذج التجريبية إنتاجًا.
- عند وجود تعارض بين محادثة قديمة ووثيقة أحدث هنا، تعتمد **أحدث وثيقة محدثة في هذا المستودع**.
- لا يوجد أي ذكر للذكاء الاصطناعي داخل النظام أو الكود النهائي.

## رابط النظام الحالي

https://ceo-msajed.pages.dev/

الواجهة الحالية مرتبطة ببيانات النظام الحقيقي للقراءة وبقاعدة `msajed-ceo-erp` للكتابة الجديدة. قاعدة `msajed-tasks` القديمة تبقى مرجعًا Read-only خلال الانتقال.

الاستضافة الحالية للواجهة: **Cloudflare Pages**، والمستودع في GitHub هو مصدر الكود.


## نقطة الاستمرار الحالية

التركيز الحالي: استكمال **قسم الصلاحيات** وتفصيل صلاحيات الإحالة والإسناد، ثم العودة إلى قسم المهام بعد اعتماد هذا الجزء.

قسم المعاملات منفذ فعليًا، وقسم المهام هو المرحلة التالية بعد إقفال الصلاحيات الحالية.

ابدأ في أي محادثة جديدة من:
- `docs/HANDOFF.md`
- `docs/PROJECT_STATE.md`
- `docs/tasks/LEGACY_INVENTORY.md`
- `docs/tasks/SPEC.md`
