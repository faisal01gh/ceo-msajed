## الأداء والأمان — الحالة الحالية

تم تنفيذ:
- قراءة قائمة المعاملات عبر RPC مباشر authenticated/PostgREST بدل تمرير القائمة كاملة عبر Edge.
- تحميل بيانات البداية بالتوازي.
- قياس استعلام قائمة المعاملات داخل PostgreSQL بحوالي **26 ms** في اختبار مدير المكتب.
- Preconnect إلى Supabase.
- Service Worker للأصول الثابتة.
- Partial rerender للقائمة والعدادات بدل إعادة رسم التطبيق كاملًا.
- Event Delegation لأزرار صفوف المعاملات.
- Timeout قدره 15 ثانية لطلبات الشبكة الأساسية.
- تنظيف أحرف التحكم في Excel.
- منع روابط مرفقات جديدة بغير HTTP/HTTPS.
- Content Security Policy.
- Publishable Keys فقط في الواجهة، ولا يوجد Service Role في الكود العام.
- RLS على الجداول المعرضة.
- Security Advisor وPerformance Advisor تمت مراجعتهما.

ملاحظة أمنية متبقية:
- Leaked Password Protection في Supabase Auth غير مفعلة حتى الآن.

الجلسة:
- ما زالت Tokens في `sessionStorage`.
- الحل الأقوى مستقبلًا: Cloudflare Worker/BFF + HttpOnly Secure Cookies إذا اعتمده فيصل.

## قسم الصلاحيات — الحالة الحالية

تم إنشاء قسم «الصلاحيات».

المرجع:
`docs/permissions/SPEC.md`

الحالي:
- قسم «الصلاحيات» يظهر فقط لمدير مكتب الرئيس التنفيذي، وهو الوحيد الذي يديرها.
- أول تبويب: «المعاملات».
- كل صلاحيات المعاملات تظهر في شاشة الإدارة لكل مستخدم وتكون قابلة للتعديل من مدير المكتب؛ الدور يعطي Default فقط، والتنفيذ الفعلي يطبق User Override في الخلفية.
- التبويبات المستقبلية تضاف مع الأقسام الجديدة.
- الصلاحيات مزيج من Role defaults + User overrides.
- تعديلات الصلاحيات تسجل في Audit.
- صلاحيات الإحالة والإسناد مفصلة وليست مفتاحًا عامًا فقط: رفع للمدير، إسناد داخل الإدارة، داخل القطاع، قطاع آخر، إدارة مساندة، للمساعد، تحويل مساعد، ورفع للرئيس.
- أقسام النظام تظهر في عمود جانبي زجاجي على يمين الصفحة.

التنفيذ المتحقق في قاعدة `msajed-ceo-erp`:
- 19 صلاحية معاملات مستقلة، وكلها تظهر قابلة للتعديل لمدير مكتب الرئيس التنفيذي.
- أزيلت صلاحية `transactions.assign` العامة بعد استبدالها بصلاحيات الإحالة والإسناد التفصيلية.
- `view_all` و`act_all` و`delete_hard` تطبق فعليًا كصلاحيات قابلة للـOverride وليست قيود مسمى ثابتة.
- يدعم النظام حفظ Override لحساب تشغيلي قبل ربطه بـSupabase Auth ثم استخدامه عند التفعيل.
- `transactions-api` المنشورة: Version 25 في آخر تحقق.
- تم اختبار تغيير صلاحية حساسة مع Audit داخل Rollback بنجاح.
- RPC الداخلية الإدارية غير متاحة مباشرة لـ`authenticated`؛ المدخل الإداري يمر عبر Wrappers مرتبطة بـ`auth.uid()`.

فهد وليد الرشيد:
- `assistant_secretary`
- سكرتير لهايف الدويش.
- ليس مساعدًا.
- لا يرث صلاحيات المساعد.
