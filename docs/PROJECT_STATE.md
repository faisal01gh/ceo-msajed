# حالة المشروع الحالية

آخر تحديث مرجعي: 2026-10-02

## المرحلة الحالية

تم **إقفال المتطلبات الوظيفية الأساسية لقسم المعاملات**، والمرحلة الحالية هي بدء التنفيذ الحقيقي للقسم داخل `ceo-msajed` قبل الانتقال إلى قسم المهام.

تم العمل على:
- توحيد مفهوم المعاملة.
- تحديد الأدوار والصلاحيات ومسارات الرفع والإحالة.
- تحديد تبويبات صفحة المعاملات.
- تحديد الإدارة المسؤولة والإدارات المساندة.
- تحديد إجراءات العمل مقابل التوجيه مقابل سبب الرفع والقرار المقترح.
- تحديد منطق الإغلاق وإعادة الفتح.
- تحديد PDF وExcel ونسخ واتساب.
- ربط النماذج التجريبية ببيانات الموظفين والإدارات.

## الخطوة التالية

تم إلغاء مسار Figma.  
المسار المعتمد الآن هو **التنفيذ المباشر**:

1. بناء الواجهة داخل `ceo-msajed`.
2. توفير رابط تشغيل فعلي.
3. تسجيل دخول حقيقي.
4. قراءة بيانات حقيقية من قاعدة النظام السابق `msajed-tasks` في المرحلة الأولى.
5. منع الكتابة على قاعدة النظام السابق حتى اعتماد كل وحدة.
6. استخدام `msajed-ceo-erp` كبيئة التطوير الجديدة للدخول الموحد والجداول الجديدة والكتابة التجريبية.
7. نقل كل وحدة تدريجيًا من العرض المتوافق مع النظام السابق إلى الجداول الجديدة بعد اعتمادها.

## مرجع الهوية البصرية

الهوية المرجعية للنظام السابق موجودة في:
`faisal01gh/ceo-office-tasks`

يجب الحفاظ على:
- الألوان.
- الهيدر.
- البطاقات.
- الأزرار.
- الخطوط.
- الطابع العام.

مع إعادة توزيع صفحة المعاملات حسب المواصفة الجديدة.

## حالة الإنتاج

قاعدة النظام السابق `msajed-tasks` تعتبر **بيئة إنتاج ومرجع بيانات حقيقي**.
النسخة الجديدة يمكنها قراءتها في المرحلة الأولى، لكن لا تكتب عليها ولا تغير مخططها إلا باعتماد صريح من فيصل.
