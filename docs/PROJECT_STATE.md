## تسجيل الدخول

يدعم التطبيق حاليًا تسجيل الدخول الحقيقي بالحسابات الموجودة في النظام السابق:
- حسابات CEO/Portal القديمة باسم المستخدم.
- حسابات Supabase Auth القديمة بالبريد الإلكتروني.

يتم التحقق من الجلسة في الخلفية قبل السماح بعمليات المعاملات.

**الهدف النهائي ما زال:** نقل الهوية إلى Supabase Auth في `msajed-ceo-erp` بحيث يكون لكل مستخدم حساب واحد متعدد الأدوار والصلاحيات. لا يتم نسخ كلمات المرور أو تجزئاتها إلى GitHub.

## الأمان

- لا يوجد Service Role أو Secret في GitHub أو الواجهة.
- الكتابة الجديدة تتم في `msajed-ceo-erp`.
- `msajed-tasks` لم يتم تعديلها.
- RLS مفعّل على الجداول المعرضة.
- الجداول الانتقالية الداخلية محجوبة عن anon/authenticated.
- تمت مراجعة Security Advisor وPerformance Advisor بتاريخ 2026-10-03.
- لا توجد حاليًا ملاحظة Security Advisor حرجة على جداول المعاملات؛ الملاحظات المتبقية INFO لجداول داخلية ذات RLS بدون سياسات عميل عمدًا.
- ملاحظات الأداء الحالية INFO عن Indexes جديدة لم تجمع استخدامًا كافيًا بعد.

## تحديث 2026-10-03 — الحسابات والأداء

- اعتماد ترحيل الحسابات التشغيلية فقط، واستبعاد حسابات الاختبار.
- سجل الحسابات الموحد يحتوي 12 حسابًا تشغيليًا.
- تم ربط 11 حسابًا مسبقًا بـSupabase Auth الجديد، والمتبقي يُفعّل عند أول دخول.
- كل الحسابات المهاجرة مطالبة بتغيير كلمة المرور عند أول دخول للنظام الجديد.
- لا يتم تغيير كلمة مرور النظام القديم.
- بعد تعيين كلمة المرور الجديدة يعتمد النظام الجديد على Supabase Auth الجديد.
- معالجة المعاملات القديمة المفتوحة حسب آخر مسؤول/إحالة مؤكدة:
  - 57 معاملة مفتوحة جاهزة بالسياق الجديد.
  - 3 منها بقيت عند الرئيس التنفيذي كما كانت.
  - معاملتان فقط تحتاجان مراجعة لغياب دليل قديم كافٍ.
- تحويل قراءة قائمة المعاملات ودليلها إلى RPC مباشر authenticated عبر PostgREST لتقليل زمن Edge.
- تحميل بيانات بداية الصفحة بالتوازي.
- استعلام القائمة داخل PostgreSQL تم قياسه بنحو 41 ms.
- Cloudflare Pages ليس مطلوبًا حاليًا لعلاج بطء الـAPI؛ يمكن بحثه لاحقًا للاستضافة/النطاق فقط بعد قياس التحسينات الحالية.

3. إكمال الانتقال النهائي من هوية النظام السابق إلى Supabase Auth في `msajed-ceo-erp`.
4. اختبار End-to-End لمسارات الإحالة/الرفع/الرفض/الإغلاق/الاسترجاع.
