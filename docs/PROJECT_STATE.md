# حالة المشروع الحالية

آخر تحديث مرجعي: 2026-10-02

## المرحلة الحالية

نحن في مرحلة **إقفال تصميم ومتطلبات صفحة المعاملات بالكامل قبل الانتقال إلى قسم المهام**.

تم العمل على:
- توحيد مفهوم المعاملة.
- تحديد الأدوار والصلاحيات ومسارات الرفع والإحالة.
- تحديد تبويبات صفحة المعاملات.
- تحديد الإدارة المسؤولة والإدارات المساندة.
- تحديد إجراءات العمل مقابل التوجيه مقابل سبب الرفع والقرار المقترح.
- تحديد منطق الإغلاق وإعادة الفتح.
- تحديد PDF وExcel ونسخ واتساب.
- ربط النماذج التجريبية ببيانات الموظفين والإدارات.

## الخطوة التالية

إنشاء تجربة Figma تفاعلية لصفحة المعاملات قبل برمجتها في النظام الحقيقي.

## مرجع الهوية البصرية

الهوية المرجعية للنظام السابق موجودة في:
`faisal01gh/ceo-office-tasks`

يجب الحفاظ على:

- الهيدر.
- البطاقات.
- الأزرار.
- الخطوط.
- الطابع العام.

مع إعادة توزيع صفحة المعاملات حسب المواصفة الجديدة.
