- لا DB أو migrations أو Edge Functions أو صلاحيات أو بيانات تشغيلية تغيّرت.
- لم يُستخدم النظام القديم أو يتصل به الفحص؛ التشغيل والواجهة يشيران إلى المشروع الجديد فقط.
