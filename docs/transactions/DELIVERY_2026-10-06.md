## حدود القبول المتبقية

- مراجعات SQL/Edge/UI المستقلة وقبول المصدر المحلي مكتملة؛ UI48 وSQL21 + reply8/10 وجسور طبقات ذات negative controls مقبولة.
- **لم ينفذ end-to-end جديد لتسجيل الدخول والرفع والرد بحسابات التشغيل بعد هذا النشر**: لا بيانات دخول تجريبية حالية محفوظة في vault. لا تستخدم فيصل، ولا reset أو إنشاء/grant أو session مصطنعة لتجاوز هذا الحد.
- Native Auth/full migration-chain replay/concurrent PostgreSQL/load ليست مثبتة بهذا renderer أو source parity. تجهيز الموظفين الحقيقيين المتبقي مشروع منفصل وغير مكتمل.
- ملفات الحسابات الستة السابقة غير المتتبعة محليًا لم تدخل commit النشر؛ قوائم كلمات المرور على سطح المكتب ليست في Git أو الأصول.
