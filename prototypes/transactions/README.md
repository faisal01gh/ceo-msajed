# نماذج قسم المعاملات

## الحالة

المواصفة المعتمدة موجودة في:
`docs/transactions/SPEC.md`

النماذج HTML التي تم إنشاؤها أثناء النقاش كانت **نماذج تجريبية متغيرة** وليست المرجع النهائي للمواصفات.

الخطوة التالية المعتمدة:
- إنشاء Prototype تفاعلي في Figma.
- بعد اعتماد تصميم Figma، يحفظ رابط/مرجع التصميم هنا.
- أي HTML لاحق يجب أن يبنى من المواصفة المعتمدة لا من نسخة تجريبية قديمة.

## قاعدة مهمة

إذا تعارض نموذج بصري قديم مع `docs/transactions/SPEC.md`، تعتمد المواصفة.
